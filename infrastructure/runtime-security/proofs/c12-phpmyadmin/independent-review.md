## Explicit limits and nonblocking observations

1. **Application directory metadata is not wholly identical.** `/var/www/html` changes from mode `0555`, uid33:gid33 to mode `02755`, uid0:gid33. It is the sole changed directory entry in the compared application tree. Neither version grants write permission there to Apache uid33; regular file permissions and ownership remain identical. Do not summarize this as whole-tree owner/mode parity. The frozen public claim already limits app parity to files/symlinks; this is an additive precision note, not a rewrite of historical proof.
2. **Lossy ASCII transliteration differs:** glibc turns `café` into `cafe`; GNU libiconv produces `caf'e`. Both retained observations produce `EURss` and preserve the tested CP1251 Cyrillic conversion. Actual PMA Cyrillic import is verified. This is not complete libc/locale/encoding parity, and arbitrary lossy ASCII exports may differ.
3. **Bzip2 export is absent in the unchanged PMA baseline.** Bzip2 import is verified. The candidate does not claim to introduce an export feature the application lacks.
4. **Reproducibility is constrained, not bit-for-bit guaranteed.** Bases and PHP source are immutable; APK names/versions are fixed and normal signatures enforced. APK mirrors must retain those versions. Payload hashes are recorded at build time rather than predeclared in the lock; future repackaging would change observed evidence and image digest. Compiler timestamps/build nondeterminism and multi-platform equivalence are not assessed. The proof applies to linux/amd64.
5. Alpine community PHP maintenance follows the active branch and requires timely package/branch refresh. Changing distro/advisory coverage is not proof that each old Debian advisory was individually fixed. Two lower-severity unchanged Composer findings remain.
6. This review did not rerun the 75/24 runtime fixtures or inspect production data. It verified retained runner logic, source hashes, exact image identity, actual records and cleanup outcomes. It does not broaden their stated behavioral coverage.
