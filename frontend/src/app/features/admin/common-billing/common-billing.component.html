Связи общих счетов

Связь объединяет компании одного плательщика в один общий счёт. Здесь: изменить эту связь, добавить или убрать её компании, перейти к другой. Новую связь создают в редакторе компании. @if (selectedAccount()) { {{ selectedAccount()?.enabled ? 'связь включена' : 'связь выключена' }} }
expand_more
Как работать со связями
  • Создать. В редакторе компании: блок «Общий счет» → включите его и добавьте другие компании. Общий счёт появится сам, когда у компании связи будет заказ.
  • Добавить или убрать компанию. В блоке «Эта связь» ниже: поле «Добавить компанию» или «−» у компании. Срабатывает сразу.
  • Изменить. Поправьте поля в «Эта связь» и нажмите «Сохранить настройки».
  • Удалить. Связи не удаляются: снимите «Связь активна для новых заказов» и сохраните. Компании выйдут из связи, неоплаченные заказы текущего счёта вернутся к оплате по отдельности.
  • Открыть другую связь. Блок «Перейти к другой связи» в конце раздела.
