Приложение «Компания О!» для Android

Если уже установлена версия 1.0.74–1.0.77

Скачайте APK версии 1.0.78 ниже и установите поверх текущего приложения. Удалять приложение и заново входить не нужно. Обновление также может появиться внутри приложения.

Если установлена старая версия 1.0.73 или ниже

Важное изменение: версии 1.0.74 и новее подписаны новым ключом. Android не может установить их поверх приложения со старой подписью.

Сначала удалите старое приложение с телефона, затем установите новую версию. При удалении исчезнут локальный вход и настройки приложения. Заказы, начисления и другие данные, сохранённые на сервере, останутся в вашей учётной записи.

Как перейти со старой версии

  1. Убедитесь, что помните данные для входа в свою учётную запись.
  2. Удалите старое приложение «Компания О!» в настройках Android.
  3. Скачайте APK по ссылке ниже. Если Android спросит разрешение на установку из браузера, разрешите её для этого файла.
  4. Откройте установленное приложение и войдите заново.
