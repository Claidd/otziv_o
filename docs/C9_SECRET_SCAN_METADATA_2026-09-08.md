## Результаты CI и границы приёмки

Срез C8 на 2026-09-08 04:10:45 UTC: 16 успешных проверок из ожидаемых 20,
три ошибки и одна ещё не наблюдалась. Ошибки: Gitleaks, Dependency audit gate
и PR issuer. Итоговый Upstream image security gate в этом срезе ещё не появился.
Это промежуточный статус C8; он не является результатом нового коммита C9.

Полный backend прошёл для PR и push. Проверка issuer прошла для push, но PR
завершился ошибкой: после успешной проверки четырёх сценариев старта Keycloak
подготовка хранилища объектов в сценарии восстановления вернула HTTP 503
вместо 200, до запуска приложения. Из лога нельзя установить, какой из двух
подготовительных запросов отказал и почему. Cleanup завершился успешно.
Успешный push не заменяет неуспешный PR-прогон. Исправление этой ситуации
не заявляется результатом настройки Gitleaks.

Причина ошибки аудита зависимостей C8 в этой работе не переопределяется.
Подтверждённые результаты C7 и остановленный этап JTidy описаны в
[отчёте C8](C8_IMAGE_ACTIVATION_2026-09-08.md). Исключение JTidy не внедрено.
GitGuardian на C8 завершился `neutral`; это отдельный внешний статус,
который не включён в 20 ожидаемых проверок и не объявляется успешным.

Штатный локальный прогон C8 со свежей копией БД VPS прошёл: 387 миграций,
проверки входа и приложения, новый Keycloak. Его итоговый набор включает
215 Node-тестов и 27 проверок сохранности БД. Результаты относятся к ранее
зафиксированным исходникам и образам, а не к новой сборке приложения в C9.

Полная приёмка P01–P21 остаётся открытой: ошибки security gates,
производственные переходы, независимая приёмка backup/alerts, подписанное
native-обновление, минимальная версия клиента и обязательные проверки на
сервере. `main` остаётся без принудительного применения требуемых checks.
Производственное развёртывание и merge не выполнялись.

риска кибербезопасности, не уточнив конкретную операцию. Отдельно она
отклонила независимый разбор исключения JTidy по той же категории риска.
Эти этапы не повторялись.
