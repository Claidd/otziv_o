# C13 — опубликованный phpMyAdmin и проверка истории секретов

Полный архитектурный план и выпуск остаются открытыми. Этот отчёт фиксирует
проверенную замену phpMyAdmin и исправление ложных совпадений Gitleaks.
Исходный код приложения не менялся; production-развёртывание не выполнялось.

## phpMyAdmin: проверена фактическая публикация

скачивание без учётных данных завершились успешно. Остальные задачи этого
workflow не входят в это утверждение.

сохранены в [каталоге доказательств](../infrastructure/runtime-security/proofs/c12-published/phpmyadmin/hosted-verification.json).

commit, run/attempt, именованный манифест, рецепт и полная цепочка digest.

Полный скан опубликованного образа: **0 HIGH / 0 CRITICAL**, без исключений

Тесты использовали только отдельную синтетическую БД. Ресурсы очищены.

В трёх Compose-файлах заменена только ссылка phpMyAdmin. Десятая запись

Проверены все 30 ссылок репозитория; прежние девять записей не изменены.
Defaults MySQL и PostgreSQL и ограничения перехода между версиями сохранены.
Существующие изменения пользователя в рабочем дереве также сохранены.

Ограничения кандидата из [C12](C12_RUNTIME_REMEDIATION_2026-09-08.md)
остаются актуальны: некоторые преобразования в ASCII отличаются от glibc,
PHP из Alpine community требует обновления ветки, будущая доступность
закреплённых APK на зеркалах не гарантирована. Полная идентичность всех
поведенческих сценариев и воспроизводимость всего образа не заявляются.

## Gitleaks

На C12 проверка текущих файлов завершилась без находок, но скан новых
коммитов обнаружил 55 совпадений `sourcegraph-access-token` в трёх отчётах
Alloy. Случай воспроизведён на точных Git blobs: directory — 0, history — 55.
Причина — разный размер фрагментов: большое добавление в Git связывает
далёкое слово `sourcegraph` с обычными 40-значными публичными хешами.

Проверены 11 публичных значений и 37 полных строк: OCI revision metadata
и ссылки на коммиты. Коррекция ограничена сочетанием конкретного detector,
точного пути и целой исходной строки. Исходные отчёты не переписаны,
проверка истории не отключена. После исправления обработки UTF-8 directory
и history дают 0. Все 36 причинных проверок прошли; изменение хеша, поля,
пути или добавление контрольного секрета продолжает обнаруживаться.
Первый неудачный UTF-8 mapping сохранён отдельно и не объявлен успешным.

## Проверки и оставшиеся условия

Локальная проверка перед публикацией включает тесты выбора именованного
манифеста и активации, проверку всех фактических OCI-доказательств, ограничения
непрерывности БД и infrastructure/deploy contracts. Отдельная независимая
проверка пакета активации содержит 168 проверок и четыре дополнения;
новый metadata-файл связывает фактические runtime-результаты с публикацией.
Обычные Git hooks включены; в коммит включаются только проверенные файлы.

Этот отчёт подготовлен до публикации нового коммита. Его CI проверяется
отдельно; результаты C11/C12 не подменяют проверку новой версии. Точный HEAD,
ссылки на запуски и последнее состояние обязательных проверок фиксируются
в [PR №2](https://github.com/Claidd/otziv_o/pull/2). Ни успешная публикация PMA,
ни локальные проверки не означают, что все двадцать условий выпуска выполнены.

Остаются замечания Maven build-support audit и upstream MySQL/PostgreSQL,
а также MinIO/mc. Согласованный production cutover, native-обновление
с исходной подписью, независимый контур восстановления и реальная доставка
уведомлений не подтверждены. Исторический штатный локальный прогон C8
получил свежую БД с VPS и прошёл; этот этап не выдаётся за новое скачивание БД.

Работы по MinIO/mc и независимому разбору исключения JTidy ранее отклонены
автоматической проверкой из-за возможного риска кибербезопасности. Для
MinIO/mc конкретная операция в отказе не указана. Эти действия не повторялись;
исправление Maven preflight и работа с phpMyAdmin/Gitleaks относятся к другим
проверкам. Политика защиты main и обязательность двадцати проверок сохранены.
