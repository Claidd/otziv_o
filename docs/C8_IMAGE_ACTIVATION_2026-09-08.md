для проверки обновления и отката.

## Проверки кода и приёмка

Итоговый набор содержит 215 успешных Node-тестов и 27 проверок
сохранности БД, infrastructure/deploy contracts. Валидатор проверил все
30 ссылок; из них 18 используют восемь проверенных публикаций.

[Итоговая сверка C7](../infrastructure/runtime-security/HOSTED_C7_ACCEPTANCE_2026-09-08.json)
подтверждает 18 успешных и два неуспешных check names из ожидаемых 20.
Backend-артефакт push-запуска 34178744907 того же коммита C7 содержит 4 713 тестов: основной verify — 4 697 PASS и 15 SKIP,
плюс отдельный успешный замер финансового CTE. Ошибок нет. Все 679 XML сверены
с фактическими testcase; архив проверен по digest GitHub API.

Пять npm jobs выполнили десять аудитов: уязвимостей не обнаружено. Все шесть
Maven-отчётов сформированы, но Dependency audit gate не прошёл из-за двух
находок JTidy. Подготовленное точечное исключение не внедрено: автоматическая
проверка отклонила его независимый разбор из-за возможного риска
кибербезопасности. Этот этап остановлен. Правила и пороги аудита сохранены.
Upstream image security gate C7 также не прошёл на прежних закреплённых образах.
Результаты C7 не заменяют собственные результаты CI следующего коммита.

`main` фактически не защищена: в GitHub отсутствуют действующие обязательные
проверки и rulesets. Документированный список check names не означает их
принудительное применение. Настройки сервера не изменялись.

[Штатный локальный прогон](../infrastructure/runtime-security/LOCAL_IMAGE_ACTIVATION_VALIDATION_2026-09-08.json)
завершился успешно: 2026-09-08T03:08:47.288125+00:00 — 2026-09-08T03:16:20.150323+00:00, exit 0.

SHA-256, восстановил её локально, обезличил внешние учётные данные и удалил
временный дамп. Проверены 387 успешных миграций,
29 защитных настроек и восемь отключённых флагов отправки.

Keycloak обновлён локально с 26.2.5 до 26.7.3. Ссылка контейнера совпадает
с проверенным registry digest, SHA-256 provider JAR совпадает с публикацией.
Штатные проверки входа и сценариев приложения прошли; backend, frontend и
OIDC discovery возвращают HTTP 200. PostgreSQL сохранил прежний образ и том.

архив; его структура проверена через `pg_restore --list`.

Прогон использует ранее проверенный точный C6-образ приложения. Пересборка

Проверка архива не объявляется полным восстановлением, локальный результат
не подтверждает производственное развёртывание.


## Что остаётся открытым

Полный план P01–P21 не считается принятым до закрытия оставшихся security gate,
переходов производственных очередей и БД, независимой приёмки backup/alerts,

включения обязательных проверок на сервере. Доказательства OCI сохраняют
описанные в них ограничения привязки исходного Git; дополнительная сертификация
происхождения не заявляется.

Работы по MinIO/mc ранее отклонены автоматической проверкой из-за возможного
риска кибербезопасности; конкретная операция в отказе не указана. Этот этап
не повторялся. Производственное развёртывание и merge не выполнялись.
