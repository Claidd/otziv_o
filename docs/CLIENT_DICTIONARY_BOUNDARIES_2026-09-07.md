# Границы веб-справочников после P19

Дата: 2026-09-07. Это описание реализованной границы и её ограничений, а не утверждение о закрытии всего F07.

`AdminDictionariesComponent` выбирает вкладку, проверяет роль, связывает представление с состоянием конкретного домена и сообщает фасадам об уходе, скрытии и уничтожении. Универсальные `runSave`/`reloadAfterMutation`, прямые подписки на HTTP и зависимость от `AdminDictionariesApi` из него удалены. Состояние и формы создаются на экземпляр экрана; транспортные API не хранят состояние редактора.

Типы DTO пока экспортируются из того же файла и импортируются новыми API как `import type`, без обратной зависимости во время выполнения.

## Поведение поздних ответов

`DictionaryViewScope` отменяет устаревшие чтения и фильтрует результаты предыдущего посещения вкладки. Уже отправленная команда продолжает выполняться при уходе: её результат не вызывает повторный POST и не меняет новый экран. Состояние занятости завершается при фактическом завершении команды. При подтверждённом ответе записи также отменяются чтения, начатые во время этой записи: они могут содержать старые данные. Отмена происходит до обработчика успеха, чтобы его новое чтение оставалось действительным. Этот порядок проверяют два теста scope и тест настоящего HTTP-компонента.

`DictionaryEditorSession` отдельно учитывает поколение выбора и изменения формы. Это различает A → B → A, защищает новый черновик от позднего ответа сохранения и позволяет присвоить созданной записи ID без потери текста, введённого во время запроса. Назначение промотекста фиксирует составной ключ менеджер/раздел/кнопка. Сохранение настроек сохраняет прежний полный PUT-контракт; новые изменения формы и явный сброс не затираются ответом предыдущей команды.

Начальная загрузка категорий теперь заполняет список подкатегорий из вложенного `subCategories` в фактическом ответе API. Раньше он оставался пустым до обновления после команды. Дополнительного запроса для этого не добавлено. Права менеджера остаются только на чтение категорий.

## Оставшееся состояние

Компонент содержит 1228 строк, в основном метаданные вкладок, отображение, маршрутизацию и алиасы для существующего шаблона. Шаблон содержит 4385 строк и ещё не разделён на доменные дочерние компоненты. Это самостоятельная оставшаяся задача по представлению: перенос состояния и HTTP не делает большой шаблон компактным.

Файл совместимости `admin-dictionaries.api.ts` содержит 973 строки, преимущественно интерфейсы DTO и делегирование. Дальнейшее физическое разделение DTO требует сохранить импорты совместимости; здесь не создавался второй ручной источник контрактов. Настройки сообщений и монитор остаются крупными, но принадлежат своим конкретным доменам; отдельные формы внутри этих доменов можно разделять при последующих изменениях.

Данный документ не подтверждает завершение всех остальных экранов web/mobile, общего `ApiService`, нативной приёмки или финансовых транзакций backend: для них существуют отдельные пакеты работ и доказательства проверки.
